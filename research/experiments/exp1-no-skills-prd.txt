  What it contains:
  - Database: created with IF NOT EXISTS, using utf8mb4 and
    utf8mb4_uca1400_ai_ci, the default collation in MariaDB 11.8.
  - Rerunnable: the file first drops the view and the six tables, children
    before parents, then creates the tables parents first. CREATE OR REPLACE
    alone fails on a parent table that a child still references. Turning off
    foreign_key_checks would fix that, but the PRD does not allow SET.
  - Keys and columns: every id is a UUID defaulting to UUID_v7(). account and
    notebook use WITH SYSTEM VERSIONING to keep row history. default_flag is a
    stored column computed as IF(is_default, 1, NULL).
  - Indexes and foreign keys: the list indexes have descending columns, and
    there is a full-text index ft_note_title_body. All foreign keys are named
    fk_<table>_<parent> and cascade deletes and updates.
  - View: v_active_note gets tags from a subquery per note, not a LEFT JOIN with
    GROUP BY. This gives one row per note, keeps untagged notes (their tags is
    NULL), and avoids grouping on the longtext body column.
